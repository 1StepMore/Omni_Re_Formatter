# ADR 索引（Architecture Decision Records）

ORF 的架构决策记录。每条 ADR 记录一个**已做出的决策**：背景、选择、
后果——让「为什么这样选」可追溯。

## 流程

- 新决策 → 复制 `TEMPLATE.md` 为 `NNNN-<slug>.md`（四位递增编号），
  写完后在索引表加一行。
- ADR 是**不可变历史**：决策被推翻时写新 ADR 并把旧的标记为
  `被 NNNN 取代`，不要原地改写结论。
- 状态取值：提议中 / 已接受 / 已取代 / 已废弃。
